# Breadfast pitch by Monkeyters

Static presentation with the latest approved content, team structure, opening video and animated Last Click ending.

## GitHub Pages

Publish the main branch, repository root, under Settings → Pages → Deploy from a branch. No build command or dependencies are needed. Keep `.nojekyll` in the repository root.

All site paths are relative so the presentation works on a GitHub Pages project URL. Existing Google Drive videos need their current sharing permissions.

## Run locally

Run `python -m http.server 8000` in this folder and open http://localhost:8000.
